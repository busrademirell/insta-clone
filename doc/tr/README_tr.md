# İnsta Klonu

## 🎯 Amaç

Bu proje, [Instagram’ın temel tasarım öğelerinden esinlenerek](https://www.instagram.com/) HTML ve CSS kullanarak benzer bir kullanıcı arayüzü oluşturmayı amaçlamaktadır. Amacı, popüler bir sosyal medya platformunun tasarım mantığını anlamak ve modern tarayıcılarda basit ama tanıdık bir kullanıcı deneyimi sunmaktır.

## 🛠️ Kullanılan Teknolojiler

- **HTML5** – Sayfa yapısını oluşturmak için kullanıldı.

- **CSS3** – Stil ve düzenlemeleri uygulamak için kullanıldı.

- **Bootstrap-5** – Responsive tasarım ve hazır bileşenler için kullanıldı.

## ✨ Özellikler

- Instagram’dan esinlenen, sade ve temiz bir kullanıcı arayüzü

- Düzen ve stil tamamen HTML ve CSS kullanılarak oluşturulmuştur

- Gönderi kartları, kullanıcı adları ve temel etkileşim alanları gibi temel UI öğeleri

- Eğitim ve öğrenme amaçlı oluşturulmuş bir tasarım deneyi

## 🚀 Kurulum ve Çalıştırma

1. Repoyu bilgisayarınıza klonlayın:

```bash
git clone https://github.com/busrademirell/insta-clone.git
```

2. İlgili proje klasörüne gidin:

```bash
cd proje-adi
```

3. index.html dosyasını tarayıcınızda açın ve projeyi görüntüleyin.

---

## ⚠️ Sorumluluk Reddi

- Proje **yalnızca eğitim ve deneyim amaçlıdır**; ticari kullanım için uygun değildir.
- Tasarım ve kod yapısı, öğrenme sürecini kolaylaştıracak şekilde **sade tutulmuştur**.
- Projeyi inceleyerek **HTML ve CSS öğreniminizi pekiştirebilirsiniz**.

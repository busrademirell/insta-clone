# İnsta Clone

## 🎯 Purpose

This project aims to create a similar user interface using HTML and CSS, [inspired by Instagram's core design elements](https://www.instagram.com/). Its goal is to understand the design logic of a popular social media platform and deliver a simple yet familiar user experience on modern browsers.

## 🛠️ Technologies Used

- **HTML5** – Used to create the page structure.

- **CSS3** – Used to apply styling and layout

- **Bootstrap-5** – Used for responsive design and ready-made components.

## ✨ Features

- A simple and clean user interface inspired by Instagram

- The layout and styling are created entirely using HTML and CSS

- Basic UI elements like post cards, usernames, and basic interaction areas

- A design experiment created for education and learning purposes

## 🚀 Installation and Operation

1. Clone the repo to your computer:

```bash
git clone https://github.com/busrademirell/insta-clone.git
```

2. Navigate to the relevant project folder:

```bash
cd project-name
```

3. Open the index.html file in your browser and view the project.
